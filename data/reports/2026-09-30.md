# Stellar — o que rolou em 30/09/2026

**Resumo em 3 linhas** — A Stellar Development Foundation lançou o Soroban Rust SDK v28, consolidando o suporte ao Protocol 28 (ativado em 16/09) com migração de dados de contrato, eventos esparsos e referências de executável via CAP-85. A cobertura sobre "integração Stellar × BVNK (Mastercard)" voltou a circular, mas o fato é de 22/09 — não é novidade de ontem. Dia de consolidação institucional e técnica, sem grande anúncio de parceria ou catalisador de mercado isolado.

## 🚀 Lançamentos e produtos

- **Soroban Rust SDK v28 lançado, suportando o Protocol 28.** O release traz cinco mudanças principais: Spec Shaking v2 (eliminação de tipos não usados nas specs de contrato), migração de dados de contrato (campos novos como `Option`, campos removidos são ignorados, sem precisar de versionamento manual), publicação esparsa de eventos (campos `None`/vazios somem do map publicado), referências de executável via CAP-85 (uma frota de contratos pode ser atualizada com uma única troca de referência de Wasm) e testes de contratos nativos via `Env::upload` sem compilar para Wasm. Requer `stellar-cli v25.2.0+`. [Stellar (oficial)](https://stellar.org/blog/developers/soroban-rust-sdk-v28)
